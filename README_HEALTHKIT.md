# Saiya

Всё работает на устройстве. Единственные внешние запросы: Open-Meteo (погода, без ключа) и, по желанию, Gemini.

## Функции
- Apple Health: сон (без двойного учёта), шаги, тренировки, пульс покоя, калории, дистанция, этажи, HRV, дыхание
- Личная норма: последние 7 дней против предыдущих; паттерн «будни vs выходные»
- Настроение / энергия / стресс + экранное время (вручную, см. ниже)
- Календарь (EventKit): свободное время вечером 17–22
- Погода (Open-Meteo) по примерному местоположению; координаты не хранятся
- Одна миссия в день с учётом погоды и свободного времени, XP, уровни, streak
- AI-инсайт и AI-чат (Gemini): выключены по умолчанию; ключ вводится в приложении (⚙︎) и хранится в Keychain
- Локальные советы без AI, демо-режим, цель по шагам, вода
- **Баланс дня** (0–100): кольцо в шапке «Сегодня», по тапу — разбор по сну, шагам, воде, заданиям и самочувствию
- **Фокус-таймер** (10/25/45 мин): XP за сессию, уведомление, если свернул приложение
- **Дневник**: мысль дня, выбор настроения смайлом, записи хранятся только на устройстве; автозадание «Запись в дневник»
- **Итоги недели**: сон, шаги, вода, настроение, фокус, главное за неделю + кнопка «Поделиться»
- **Динамика самочувствия**: график настроения / энергии / стресса на экране «Путь» и в итогах недели
- **Уровни с названиями** (Росток → Легенда), конфетти и всплывающие сообщения при новом уровне и при выполнении всех заданий
- Смайлы настроения и заметка в отметке дня, «Мысль дня», pull-to-refresh на «Сегодня», очистка чата, 5 новых наград
- Экран «Источники и приватность»: переключатели, ключ, удаление всех данных

## Запуск
1. Открой `saiya.xcodeproj`, выбери свою Team в Signing & Capabilities (HealthKit уже включён).
2. Запусти на реальном iPhone с iOS 16+.
3. Разреши Health, календарь и местоположение при запросах.
4. Для AI: ⚙︎ на экране «Сегодня» → включи переключатель и вставь Gemini API-ключ.

## Ограничение: Screen Time
iOS не отдаёт данные Screen Time сторонним приложениям (через Family Controls они доступны только внутри специального расширения и не могут быть переданы приложению). Поэтому экранное время вводится вручную в отметке дня.
